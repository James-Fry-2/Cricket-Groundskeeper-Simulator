Cricket Groundsman: playtest build for Windows
==============================================

Thanks for testing. Guide.md, in this folder, explains the game in a few pages.

Starting it
-----------
1. Unzip this folder somewhere, for example your Desktop. Keep the content folder next to
   CricketGroundsman.exe: the game reads it.
2. Open Windows Terminal (it's on Windows 11; on Windows 10 it's free from the Microsoft Store).
   The older Command Prompt works too, but draws the game's boxes less well.
3. Type "cd " (with a space), drag this folder onto the window, press Enter, then type
   .\CricketGroundsman.exe and press Enter.
   (Double-clicking CricketGroundsman.exe also works, in a smaller window.)

The first time, Windows may say it protected your PC, because this test build isn't signed.
Click "More info", then "Run anyway".

Make the window at least 80 characters wide.

Stopping and carrying on
------------------------
Type q to quit at any time. The game saves after every turn; next time it asks whether to carry
on where you left off.

Sending it back
---------------
Your seasons are in Documents\Cricket Groundsman, one folder per season. When you've finished
(or given up), zip that season's folder and send it with the questionnaire. Nothing is sent
from your PC on its own. If you jot notes while playing, save them as notes.txt in the
season's folder.
